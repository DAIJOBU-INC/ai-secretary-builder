# context/ — 今の事実を置く場所

秘書は、ここに書いてある事実をもとに動きます。書いてあることが多いほど、一般論ではなく、自分の会社に合った答えが返ってきます。

事実が変わったら、秘書に伝えてください。秘書が古い記述を直します（自分で直してもかまいません）。各ファイルの先頭の `updated:` は、最後に直した日付です。

| 場所 | 入るもの | 誰が書くか |
|---|---|---|
| `owner/profile.md` | 自分の名前・役割・使っている道具・メールの署名・判断基準 | 名前から署名までは、初回セットアップで秘書が書く。判断基準と仕事の進め方は、あとから秘書に伝えるか、自分で書く |
| `company/overview.md` | 会社の正式名称・事業・お客さま・社内の言葉 | 会社の資料から秘書が下書きし、自分で確かめる |
| `company/decisions.md` | 判断の記録（日付つきで足していく） | 壁打ちのあと「記録に残して」と頼むと秘書が足す |
| `company/sources/` | 会社の資料そのもの（会社案内、事業計画、提案資料など） | 自分でファイルを入れる |
| `clients/` | 取引先ごとのカルテ。1社1ファイル | 「（会社名）のカルテをつくって」と頼むと秘書が作る |
| `members/` | メンバーごとの1on1の記録。1人1ファイル | 「今日の（名前）さんとの1on1を記録して」と頼むと秘書が作る |

追っている数字（売上、商談数など）を秘書に見せたいときは、秘書に「追っている数字を記録して」と頼んで、数字を伝えます。秘書が `company/kpi.md` に書き、週次レポートが前の週と並べて見せます。

## 社外に出さないもの

`company/kpi.md` の数字と、`members/` の記録は、社外の人に見せる文面に秘書が書かない決まりです。このフォルダごと、ほかの人と共有しないでください。
