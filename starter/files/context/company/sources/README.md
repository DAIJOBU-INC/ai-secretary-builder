# sources/ — 会社の資料を入れる場所

会社の資料を、このフォルダにそのまま入れます。PDF、Word、PowerPoint、Excel のどれでもかまいません。

入れたら、秘書に「資料を読んで、会社の概要を直して」と頼みます。秘書が `context/company/overview.md` を下書きし、確かでない所に「（要確認）」を付けて見せます。

## 最初に入れるとよい資料

| 役割 | 資料 |
|---|---|
| 経営者 | 事業計画・中期計画、経営会議や取締役会の資料、会社案内 |
| 役員・部門責任者 | 経営会議の資料、部門の目標や計画、組織図 |
| 営業 | 提案資料・サービス紹介、価格表・見積のひな形、取引先の一覧 |

資料が手元に無ければ、会社のホームページのURLを秘書に伝えるだけでも始められます。

## 入れる前に確かめること

- 給与、人事評価、個人の連絡先が入った資料は、会社のルールで持ち出してよいものかを確かめてから入れます
- パスワードや認証情報が書かれたファイルは入れません
