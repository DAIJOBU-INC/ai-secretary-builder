# work/ — 秘書が作ったものが貯まる場所

秘書が作った工程表・日報・会議の準備資料・議事録が、日付つきのファイル名で増えていきます。前のファイルは消えません。

| 場所 | 入るもの | こう頼むと作られる |
|---|---|---|
| `daily/` | 工程表、日報、未返信チェック | 「今日の工程表をつくって」「今日の日報をまとめて」「返信漏れてない？」 |
| `weekly/` | 週次レポート | 「今週の振り返りをつくって」 |
| `mtg/` | 会議の準備資料、議事録 | 「明日の（会議の名前）の準備資料をつくって」「さっきの打ち合わせの議事録を出して」 |

次のフォルダは、はじめは無く、そのスキルを最初に使ったときに秘書が作ります。

| 場所 | 入るもの |
|---|---|
| `mail/` | 返信の下書きの控え（残したいときだけ） |
| `research/` | 調べものの結果 |
| `clips/` | 記事・URLの要約 |
| `reading/` | 読書メモ |
| `content/` | 記事・発信文の下書き |
