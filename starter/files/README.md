# AI秘書スターター

Claude Code で開くだけで、自分専用のAI秘書として使えるフォルダです。朝の工程表、会議の準備、議事録、メールの返信の下書き、日報などを、ひとことで頼めます。

## はじめ方（3手順）

1. **このフォルダを置く**: 自分だけが見られる場所（例: ホームフォルダのすぐ下、書類フォルダ）に置きます。会社の共有フォルダには置きません。OneDrive などで自動的に同期されるフォルダに置いてよいかは、会社のルールに合わせます
2. **Claude Code で開く**: Claude のデスクトップアプリで「Code」タブを開き、このフォルダ（`CLAUDE.md` が入っているフォルダ）を選びます。フォルダを信頼するかの確認が出たら、許可します
3. **「はじめまして」と入力する**: 秘書が5つ質問します（名前と会社・役割・使っている道具・メールの署名・秘書の呼び名）。答え終わると、自分専用の設定ができます

カレンダーやメールをつなぐと、秘書が予定やメールを自分で読めるようになります。つなぐ操作は、Claude の「設定」→「コネクタ」で行います。会社の Microsoft 365 をつなぐには、会社の管理者が先に一度、許可の操作をしておく必要があります。つながっていなくても、予定やメールを貼り付ければ使えます。

## こう頼む

ふだんは、下の「こう頼む」のような言葉で話しかければ、秘書が合うスキル（決まった手順）を選びます。スキル名を入力して呼ぶこともできます（例: `/daily-schedule`）。

## フォルダの地図

| 場所 | 入るもの |
|---|---|
| `CLAUDE.md` | 秘書への自分のルール。「毎回こうしてほしい」を足していく場所 |
| `context/` | 今の事実。自分のプロフィール、会社の概要、判断の記録、取引先、メンバー |
| `context/company/sources/` | 会社の資料を入れる場所。パソコンでこのフォルダを開き（Mac は Finder、Windows はエクスプローラー）、`context` → `company` → `sources` の順に開いて資料を入れる。入れたら「資料を読んで、会社の概要を直して」と頼む |
| `work/` | 秘書が作ったもの。工程表・日報・会議の準備資料・議事録が、日付つきで増えていく |
| `.claude/` | 配布された共通ルールとスキル。ふだんは触らない |

## 秘書が守ること

- メールは下書きまで。送信・転送・予約送信はしません。送信ボタンは自分で押します
- チャットへの投稿も、文面を作るところまで。投稿は自分でします
- 金額、人の評価、社内の段取りは、社外の人に見せる文面に書きません
- パスワードなどの認証情報は、読みません・書きません

## 確認の画面が出たとき

秘書がカレンダーやメールなどの道具を使うときと、Webページを開くときに、許可を求める確認が出ます。

- **読むだけの操作**（予定を見る、メールを探す）: 許可してかまいません。同じ確認を毎回出したくなければ、「常に許可」にあたる選択肢を選びます
- **送る・作る・消す操作**（メールの送信、予定の作成や削除）: 内容を読んでから、その都度決めます。この種類の確認では「常に許可」を選びません

## 困ったとき

- **スキルが動かない**: 入力欄に「/」を打って、スキルの一覧が出るか確かめます。出なければ、開いているフォルダが違います。`CLAUDE.md` が入っているフォルダを開き直します
- **初回の質問で「あとで」と飛ばした所に答えたい**: 「セットアップの続き」と頼みます
- **初回の質問の答えを直したい**: 「セットアップをやり直して」と頼みます
- **同じスキルが2つ出る**: プラグイン版のAI秘書スキルパックも入れていると、同じスキルが2つ並びます。どちらか片方だけにします（講師に相談してください）
- **それ以外**: 研修の講師に聞いてください
